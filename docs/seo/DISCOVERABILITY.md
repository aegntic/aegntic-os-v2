# Search and AI discoverability

Updated 17 October 2026. GEO here means generative-engine optimization, not fabricated geographic coordinates.

## GitHub surfaces

The README leads with the product's name/category, a concise factual description, current status, a working/planned capability matrix, source-linked evidence, setup and direct FAQs. Architecture diagrams have text alternatives. Public repository description/topics describe the actual project. These improve clarity and navigation; no ranking or AI-citation increase has been measured.

GitHub controls the rendered page's document head. Inserting meta, Open Graph or JSON-LD script tags in README Markdown is not a supported way to set GitHub's SEO metadata. The repository metadata/README are the relevant surfaces; an owner can separately upload an approved social preview image in repository settings. The Assembly landscape master is available, but this work does not assert that a custom GitHub social preview has been configured.

`project-facts.json` provides a public, machine-readable summary with status and evidence. `llms.txt` is a convenience index into public docs, not a standard that guarantees discovery, indexing or citations. It lives in this repository; it is not claimed to be deployed at the root of aegntic.ai.

## Future public website

The Assembly site is still a loopback review. Final canonical domain, absolute OG/Twitter image URLs, sitemap, robots directives, structured data, operator/contact details and production indexing policy need the actual approved public deployment. No geographic business address or coordinates were supplied, so no location tags were invented. No new public deployment or tracking service was added here.

For a future production page: use a unique title/description, canonical URL, crawlable text, descriptive image alternatives, matching Open Graph/Twitter cards and truthful SoftwareApplication/Organization metadata. Only mark up content actually visible on the page. Keep private state behind access controls; crawl directives do not supply those controls.
