# Licensing status — not yet published

This new application's intended policy is Aegntic Community plus a separate commercial agreement: ongoing free personal use; eligible organizational use below both US$1,000,000 trailing annual gross revenue and 1,000 monthly active users; monetary commercial recognition once either threshold is reached, with attribution retained.

The working license from the architecture research remains a draft. The legal licensor, applicable release scope, commercial prices and final terms must be completed before an operative grant is attached. No MIT/Apache license has been assigned to the original application code by this build.

No upstream application implementation was copied into this source tree. The outcome/workflow/control names and contracts reflect the user's requested design. Runtime/tool dependencies and any future imported code retain their separate licenses; future adoption must include the appropriate notices and ownership review. Private research repositories are not part of this source tree.
