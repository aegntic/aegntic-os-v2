# First-run contract

Build the smallest useful local V2 workspace. Accept if: (R1) five outcomes are available; (R2) validated briefs persist across storage restart; (R3) repeated request keys cannot duplicate or overwrite briefs; (R4) all six pre-launch controls require evidence or an applicability reason and preserve unresolved states; (R5) unconnected execution cannot be reported successful; (R6) browser save/retry/draft and mobile behavior work.

Owner units: store owns briefs/reviews only; HTTP owns local boundary; UI owns drafts/presentation; Pi remains the future execution authority. No model calls, remote changes, public release, payment or deployment is part of this local acceptance check.
